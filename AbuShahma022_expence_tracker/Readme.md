# ExpenseWave

ExpenseWave is a modern full-stack expense tracking application built with Next.js, TypeScript, Redux Toolkit, Node.js, Express.js, and MongoDB.

## Live Demo

Frontend: https://expensewave.vercel.app/

Backend API: https://expense-tracker-817j.onrender.com/

---

# Features

## Authentication
- User Registration
- User Login
- Logout
- Forgot Password
- OTP Verification
- Reset Password
- Protected Dashboard Routes

## Dashboard
- Expense Summary
- Monthly Expense Analytics
- Category Expense Analytics
- Responsive Sidebar Navigation

## Expense Management
- Create Expense
- Update Expense
- Delete Expense
- Search Expenses
- Filter by Month
- Pagination

## Budget Management
- Create Monthly Budget
- Budget Tracking

## Profile Settings
- Update User Profile

## UI/UX
- Responsive Design
- Modern Dashboard UI
- Dark Mode Support
- Recharts Analytics
- Toast Notifications
