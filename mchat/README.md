# mchat

A real-time chat application built with Next.js and Supabase.

# Live Demo: https://mchat-eosin.vercel.app

## Features

-  User authentication (register, login, logout)
-  Real-time messaging in chat rooms
-  Direct messaging (private, secure)
-  Online presence indicator
-  Typing indicators
-  Search rooms and DMs
-  Mobile responsive (WhatsApp-style UI)
-  Deployed on Vercel

## Tech Stack

| Next.js 14 | Frontend + API Routes |
| Supabase | Database + Auth + Realtime |
| Tailwind CSS | Styling |
| shadcn/ui | UI Components |
| Framer Motion | Animations |
| Vercel | Deployment |
