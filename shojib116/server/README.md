# ChitChat Server
Welcome to chitchat a realtime messaging server

## Quick Start
Setup environment variables with reference from [.env.example](https://github.com/shojib116/web-development-bootcamp-may-2026/blob/main/shojib116/server/.env.example) then
```
go run .
```

## Usage
Start the frontend and start registering user, add friends and start messaging

## Offerings
Websocket messaging server, db persistance of data, Layered architecture.
